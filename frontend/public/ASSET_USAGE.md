# KaziLayer asset usage

These original portfolio assets are supplied in editable SVG and production PNG formats.

## Clear space

Keep clear space equal to one quarter of the mark width on every side. Do not place the mark on a background that reduces contrast.

## Minimum size

- Mark in interfaces: 20 px minimum
- Horizontal lockup on screen: 160 px minimum width
- Monochrome mark: use when a single color is required

## Color

- Primary: #283C78
- Accent: #36D3A0
- Ink: #111827
- Surface: #F4F7FC

## Files

- `logo/logo-mark.svg` is the preferred scalable symbol.
- `logo/logo-horizontal.svg` is the preferred full lockup.
- `icons/favicon.svg` is the preferred modern web favicon.
- `social/social-card-1200x630.png` is the Open Graph preview.
- `tokens/brand-tokens.json` is the source for Figma and code variables.

The name and identity are concept work for a portfolio. Complete legal trademark and domain checks before commercial use.
